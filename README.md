## Features

* **Instant Search:** Filter notes in real time by title, subject, or file path.
* **Built-in Reader Mode:** Opens HTML notes in an embedded reader with a persistent top bar, subject switcher, and previous/next navigation.
* **Direct Hash Links:** Every note has a shareable URL (`#folder/file.html`).
* **Zero Dependencies:** Pure static HTML, CSS, and vanilla JavaScript — no build step required.

## Keyboard Shortcuts

| Key | Action |
| :--- | :--- |
| `/` | Focus search bar |
| `↑` / `↓` | Move selection up or down |
| `Enter` | Open selected note |
| `Ctrl + C` / `⌘ + C` | Copy selected note's relative path |
| `Esc` | Clear search or exit reader view |
