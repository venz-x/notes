Module 1

Network fundamentals and basic components

Definition

A network is the interconnection of different devices to enable data transformation and communication between them.

Nodes (network devices)

Node typeDefinitionExamples
End Nodes
শুরু / শেষ (Start / End)		Devices at the origin or final destination of a communication flow that generate or consume user data.PCs, smartphones, servers, printers
Intermediary Nodes
মাঝখানে (In the Middle)		Devices between end nodes that forward, route, filter, or regenerate signals without originating user payload data.Hub, switch, router, repeater, firewall

EXAM IDENTIFICATION TIP

To classify any device, ask: does it originate or terminate the data, or does it only pass it along? If it creates or finally consumes user data, it is an End Node. If it sits in the middle (মাঝখানে) and only forwards, routes, filters, or regenerates, it is an Intermediary Node.

Transmission medium (channel)

Wired / Guided mediaWireless / Unguided media
Physical cables guide the signal along a solid conductor or glass core: Twisted Pair (UTP/STP), Coaxial Cable, Fiber Optic cable. Electromagnetic waves travel through air or vacuum with no physical conductor: Radio Waves, Microwaves, Infrared.
Advantages: high speed, strong security, low interference.Advantages: high mobility, easy scalability.
Disadvantages: high installation cost, zero mobility.Disadvantages: signal attenuation, interference, security risks.

Module 2

Intermediary devices

Hub · Physical Layer

Uses Broadcast transmission: every incoming bit on one port is blindly replicated to all other connected ports. It is obsolete in modern networks.

AdvantagesDisadvantages
Cheap and simple to wire.Creates a single collision domain, wastes bandwidth, and poses severe privacy risks because all nodes receive all frames.

Switch · Data Link Layer (LAN)

Facilitates communication within the same network (LAN) using intelligent Unicast (as well as multicast/broadcast) frame forwarding based on hardware MAC addresses.

AdvantagesDisadvantages
Eliminates frame collisions per port, improves local throughput, and enhances privacy compared to a hub.Costs more, and cannot route traffic between different IP subnets.

Router · Network Layer

Enables communication between different networks (WANs/LANs) by inspecting logical IP addresses and selecting the optimal path for packets.

AdvantagesDisadvantages
Isolates broadcast domains, connects heterogeneous networks, and supports dynamic path selection.Higher processing latency and configuration complexity.

Repeater · Physical Layer

Combats signal attenuation over long distances: it receives a weak or corrupted signal, regenerates it to its original bit pattern and amplitude, and retransmits it.

AdvantagesDisadvantages
Extends physical cable distance inexpensively without losing signal quality.Cannot filter traffic, segment collision domains, or connect different network architectures.

Firewall · Security (hardware or software)

Inspects incoming and outgoing network traffic and permits or blocks packets based on predefined security rules.

AdvantagesDisadvantages
Protects internal networks from unauthorized access and malicious traffic.Strict inspection rules can add processing delay and require ongoing rule maintenance.

QUIZ JUSTIFICATION BOX 1

Prompt: "Switch is an intermediary node because it generates data (True or False). Justify it!"
Answer: False. A switch is indeed an intermediary node, but not because it generates data. It does not generate user data: End Nodes generate and consume data, whereas a switch sits in the middle (মাঝখানে) to inspect MAC addresses and forward existing frames within the same network.

Module 3

Network evaluation criteria

Definition

An effective network must satisfy all three evaluation criteria (৩ টা থাকলে ভালো).

CriterionMeasures
1. Performance
*** High Priority		How effectively and rapidly the network transfers data (কতটা effective perform করছে), evaluated via Bandwidth, Throughput, Latency, Packet Loss, and Jitter.
2. ReliabilityConsistency and fault tolerance: whether performance drops repeatedly (বার বার performance down হচ্ছে), how often link failures occur, and how quickly the system recovers.
3. SecurityWhether the network is protected (Secure কি না) against unauthorized access, data breaches, eavesdropping, and accidental or malicious modification.

Module 4

Bandwidth and throughput

Bandwidth

Definition

Bandwidth is the maximum theoretical amount of data that can be transmitted over a communication channel in a given unit of time (সর্বোচ্চ কি পরিমাণ ডেটা পাঠাতে পারে). Unit: bps (bits per second).

EXAM BOX: পরীক্ষার জন্য 3 Bandwidth with unit

BandwidthIn bps
500 kbps5 × 105 bps
10 Mbps10 × 106 bps
1 Gbps109 bps

Throughput

Definition

Throughput is the actual rate of data successfully delivered across the network per unit of time (Actual data পাঠানোর হার), also measured in bps.

Example: a network has a bandwidth of 20 Mbps, but devices communicating inside it achieve an actual throughput of only 200 kbps.

Worked problem

Problem: A network with a bandwidth of 10 Mbps can pass only an average of 12,000 frames per minute, with each frame carrying an average of 10,000 bits. What is the throughput of this network?

Throughput = (frames × bits per frame) / time
= (12,000 × 10,000 bits) / 60 s
= 120,000,000 bits / 60 s
= 2,000,000 bps = 2 Mbps

Interpretation: the link capacity (bandwidth) is 10 Mbps, but the realised throughput is only 2 Mbps, which is 20% utilization.

QUIZ JUSTIFICATION BOX 2

Prompt: "Throughput will always be less than Bandwidth. Justify it (Quiz)."
Answer: Bandwidth is the theoretical upper limit of the physical channel, while real-world throughput is lower: Throughput < Bandwidth. The gap comes from protocol header overhead, network congestion, queuing and processing delays at intermediary nodes, packet loss that forces retransmission, and physical channel noise.

Module 5

Latency, packet loss and jitter

Latency (Delay)

Definition

Latency is the total time for an entire message or packet to completely reach its destination, measured from the moment the first bit is sent (পাঠাতে কতটুকু সময় লাগে / পুরো সময় for the entire packet). Unit: seconds (s) or milliseconds (ms) (হিসাব কষব, একক সেকেন্ড).

Latency = Transmission Time + Propagation Time + Processing Delay + Queuing Delay
Latency = Tt + Tp + Tproc + Tq

ComponentDefinitionFormula
(1) Transmission TimeTime to push all bits of the packet onto the transmission medium.Message Size / Bandwidth
(2) Propagation TimeTime for a single bit to travel physically across the medium from sender to receiver.Distance / Propagation Speed
(3) Processing DelayTime intermediary nodes take to examine the packet header, check for bit-level errors, and determine the output port.Set by device speed
(4) Queuing DelayTime a packet waits in a router or switch input/output buffer before it can be processed and transmitted.Grows with congestion

Packet loss & jitter

Packet Loss: one or more transmitted packets fail to arrive at their destination, often dropped because router queues are full or the signal was corrupted. It degrades throughput and requires retransmission.

Jitter: the variation in packet arrival delay over time, which disrupts real-time audio and video streams.
