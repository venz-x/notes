Module 1

IEEE 754, bias and reserved exponents

Definitions

Bias: a number we add to the true value so every stored value is positive. Mantissa: the digits after the leading 1. Normalised: written as 1.xxx × 2e. NaN: “not a number”, the answer to something impossible like 0/0. Subnormal: a number too tiny to normalise.

4-bit signed, unsigned and biased

A 4-bit register has 16 patterns. Signed (2’s complement) reads them as −8 to +7, unsigned as 0 to 15. Biased adds 24−1 = 8 to the true value, so −8 becomes 0 and +7 becomes 15. The ordering of the patterns is then plain unsigned order, which makes comparing exponents easy.

Why Bias = 2n−1 − 1

Bias = 2n−1 − 1    (compare 24−1 = 8 above)

IEEE 754 subtracts one from 2n−1 because two patterns are reserved. With 8 exponent bits the bias is 127, so stored values 1 to 254 give true exponents −126 to +127, nearly symmetric around zero.

0000…0not 0Subnormal number

Worked example: converting (78)10

  1. Divide by 2 repeatedly: 78→39 r0, 39→19 r1, 19→9 r1, 9→4 r1, 4→2 r0, 2→1 r0, 1→0 r1. Read remainders upward: 1001110.
  2. Normalise: 1.001110 × 26.
  3. Sign = 0 (positive). Mantissa = 001110 followed by zeros to fill 23 bits (float) or 52 bits (double).
  4. Exponent: float 6 + 127 = 133 = 10000101. Double 6 + 1023 = 1029 = 10000000101.

Float result: 0 10000101 00111000000000000000000 = 0x429C0000.

Module 2

System architecture and bus operations

Definitions

Bus: a group of wires shared by the parts of the computer. Bidirectional: data can go both ways. Unidirectional: data goes one way only. Read: copy data from memory to the processor. Write: copy data from the processor to memory.

Analog vs digital

System block diagram

The data bus is bidirectional because the CPU both reads instructions and data from memory and writes results back. The address bus is unidirectional (MP → Mem) because only the MP decides which location is used. The control bus carries the R/W signal and timing.

Memory read vs memory write

Both cycles share steps 1 and 2. Only the direction of step 3 differs.

Module 3

Program translation: HLL vs assembly

Definitions

HLL: a language people can read easily, like C or Python. ASM: assembly, short commands such as ADD. MC (machine code): the 0s and 1s the CPU runs. Compiler: converts a high-level program into machine code. Assembler: converts assembly into machine code. Opcode: the part of an instruction that says what to do. Operand: the data it works on.

Anatomy of a machine instruction

The control unit reads the opcode (0100, ADD) to pick the operation and the operand field (100) to find a and b. The same shape covers y = a + b and c = a − b, only the opcode changes.

Memory organisation and capacity (8085 vs 8086)

Definitions

RAM: memory you can read and write; it forgets everything when power is off. SRAM: fast memory built from flip-flops; used for cache. DRAM: memory that stores each bit as charge in a capacitor; cheap and big but must be refreshed. ROM: memory that keeps its data without power, e.g. BIOS. Byte: 8 bits, one memory location.

Module 5

Clock, edge triggering and the instruction cycle

Definitions

Clock: a steady on-off signal that sets the pace of the processor (8086: 5 MHz). Period T: the time for one full on-off cycle, T = 1/f, so 5 MHz is 200 ns. Rising edge: the moment the signal goes 0 → 1. Falling edge: 1 → 0. Instruction cycle: the steps to finish one instruction. PC / IP: holds the address of the next instruction.

Every micro-operation is synchronised to the clock. On a rising edge, registers latch and the 20-bit address or data is driven onto the bus.

Fetch, decode, execute

  • Fetch (F): the PC/IP address goes on the address bus and the opcode is read from memory.
  • Decode (D): the control unit interprets the opcode (0100100) to find the operation and operands.
  • Execute (E): the ALU performs ADD a, b and stores the result.

Module 6

Instruction pipelining: 8085, 8086, superscalar

Exam focus: Pipelining কি? Compare 8086 and 8085

Pipelining means starting the next instruction before the last one has finished. The work is split into stages (like an assembly line), and each stage works on a different instruction at the same time.

Definitions

BIU: the part of the 8086 that talks to memory and fetches instructions early into a 6-byte queue. EU: the part that decodes and runs those instructions. WB (write back): save the result. MA (memory access): read or write memory. Superscalar: a CPU with several pipelines that finish more than one instruction per clock. IPC: instructions finished per clock.

Why 8086 pipelines and 8085 cannot

The 8085 has one unit that must finish decode and execute before the bus is free to fetch again. The 8086 splits into BIU and EU, so the BIU fetches ahead while the EU works.

Higher-order pipelines

3-stage: F, D and E each get their own clock, so three instructions are in flight at once.

Is 3-stage slower than 2-stage?

The diagrams count clock cycles, and with more stages that count goes up: n instructions take (stages + n − 1) clocks. For 4 instructions, 2-stage needs 2 + 4 − 1 = 5 clocks and 3-stage needs 3 + 4 − 1 = 6. So the diagrams are correct.

The clocks are not the same length, though. In 2-stage, one clock must fit the whole D+E job. In 3-stage, D and E are split, so each stage does less work and the clock can be shorter. A faster clock is the real gain of more stages.
