Intel 8086 Memory Banking

1 MB of memory is built from two 512 KB byte-wide banks. The 19 lines A19–A1 choose a slot in both banks at once; A0 and BHE# are active-low chip selects that decide which bank actually answers.

Why one address bus can feed both chips

The same 19 wires A19–A1 reach the address pins of both banks, so slot n is decoded in parallel in each chip. The even bank holds byte 2n and the odd bank holds byte 2n+1: one row pair per slot.

A0 and BHE# are never address bits inside the chips. They act as active-low chip selects (CS#even = A0, CS#odd = BHE#): low enables a bank, high switches it off and releases its data pins.

19 bits × 2 banks = 2²⁰ bytes = 1 MB. A word at an odd address is split into two cycles: state 3 for the odd byte, then state 2 for the next even byte.

Simplified view: the address latches (ALE / 8282) and data transceivers (8286) that sit between the CPU and the banks are omitted.
